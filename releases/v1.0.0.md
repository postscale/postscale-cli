The first stable release of the official Postscale CLI is available for macOS,
Linux, and Windows.

- Configure domains, inspect DNS records, and verify email authentication.
- Send API-native JSON from a file or stdin, or validate it locally with `--dry-run`.
- Inspect outbound messages, delivery events, received email, and webhook attempts.
- Use named OS-keychain profiles or environment credentials, with JSON output
  and explicit test/live credential context for scripts.

Download the archive for your platform and verify its SHA-256 against
`checksums.txt`. Each archive contains the CLI, README, license/notices,
changelog, and sample message. Prebuilt binaries do not require Go.

Go 1.25+ users can install with:

```sh
go install github.com/postscale/postscale-cli/cmd/postscale@v1.0.0
```

See the [installation and usage guide](https://github.com/postscale/postscale-cli/blob/v1.0.0/README.md).

Known limits: `auth status` checks local configuration, email inspection uses
resource UUIDs, and mutations are never automatically retried. The pinned SDK
omits newer response environment fields; inspect `context.credential_environment`
and `data.status`. Webhook forwarding, batch sending, and deletion are not included.

Built with Go 1.25.11. Binary downloads are unsigned; `checksums.txt` provides
SHA-256 integrity verification. See [CHANGELOG.md](https://github.com/postscale/postscale-cli/blob/v1.0.0/CHANGELOG.md).
